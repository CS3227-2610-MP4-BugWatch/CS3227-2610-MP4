# BugWatch User Guide

BugWatch helps Testers report bugs and Developers investigate and record resolutions. Accounts are provisioned by an administrator with a permanent Tester or Developer role.

## Access and first steps

1. Open your team's deployed BugWatch app URL and sign in with the account supplied for your role. The GitHub Pages site is documentation, not the running application.
2. Open **Projects**, choose an active project and select **Reports** to browse its reports.
3. As a Tester, choose **Report bug** to create a report. Save incomplete work explicitly in **My drafts**. You can request AI suggestions and review them before applying or submitting anything.
4. As a Developer, accept a report, start investigation, discuss missing information and record a resolution. The assigned Developer can request AI clarification questions when that feature is enabled.
5. Use the report's **Conversation** and **Activity** tabs to read discussion and history. Original Testers can edit eligible submitted reports; assigned Developers receive those edit notifications in **Mailbox**.

A Developer resolution is the end of the current release's lifecycle. Tester retesting, closure and return to investigation are planned future features. They are not available controls in the current app.
