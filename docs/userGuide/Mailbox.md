# Mailbox

Open **Mailbox** from the workspace navigation to see your private report updates. Currently, an assigned Developer receives an unread item when the original Tester makes a real edit to a report. The item identifies the Tester, report, project, and changed fields. Unassigned reports and unchanged saves do not create an item. See [Bug reports](Reports.md) for editing.

Select **All** to see your items or **Unread** to filter to unread items. Each item shows its read status. Select **Mark as read** to update it without leaving the mailbox, or **Open report** to mark it read and open the report. Read status persists across visits. **Delete** removes only the mailbox item; it does not delete the report, discussion, or history.

The mailbox requires a signed-in account with a valid profile and shows only that account's items. If loading fails, select **Retry** or **Reload mailbox**; a failed load is not an empty mailbox. If saving read status fails, retry before opening the report. If deletion cannot be confirmed, retry deletion or reload to check the result.
