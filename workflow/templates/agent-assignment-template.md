# Focused Agent Assignment

Adapt this to the assigned role; include enough context to do correct work, without repeating the entire feature plan. There is no fixed word/token cap. Do not drop a requirement to make the assignment shorter.

- **Outcome and task IDs:** The observable result required from this agent; relevant acceptance criteria.
- **Authoritative context:** Exact plan/artifact paths and revision, relevant sections or symbols, existing behavior and mandatory role instructions. Link shared material rather than copying whole documents. Include a short explanation of anything needed immediately.
- **Owned files and boundaries:** Exact files/modules; allowed changes, exclusions, dependencies and any ownership transfer. Other agents share the workspace: preserve their edits and route conflicts to the coordinator.
- **Contract:** Existing interface reference or agreed inputs, outputs, errors, side effects and boundary behavior that this task consumes/produces. Resolve blocking interface decisions before independent edits.
- **Checks and evidence:** Exact commands/scenarios and expected outcomes, test environment, unavailable prerequisites and completion evidence. Keep provisional, skipped and executed results distinct.
- **Return:** Submission ID, reviewed revision/state, changes, actual results, assumptions/blockers and source links; completion awaits independent review under existing rules.

Read additional context when an interface, test failure or dependency requires it. Report the gap and retrieve the relevant source; do not guess or refuse necessary reading because it was not in the initial packet. Follow mandatory references even when the assignment is short. Do not copy secrets or irrelevant chat history into handoffs.
