# Exploration Recap

Use the applicable items in conversation; this template is not authorization to write an artifact or start implementation. Keep a small task's recap short.

- **Goal and actor:** What the user needs and who does it.
- **Current behavior:** Verified starting point and relevant source.
- **Ordinary flow:** Entry, action and visible saved/result state, in simple words.
- **UI mockup:** Labeled proposed image and material user feedback for visible UI changes; N/A for non-UI work. Distinguish unresolved design choices from confirmed behavior and actual app evidence.
- **Important failures or state changes:** Trigger, user-visible outcome, retained data and recovery where relevant.
- **Confirmed decisions:** Decision and user/requirement source.
- **Recommendations:** Proposed behavior and reason, clearly unconfirmed.
- **Open decisions:** Blocking question, decision owner and affected work; None if resolved.
- **Excluded:** Deliberately deferred behavior and why.
- **Next authorized step:** Existing authorization and next action; ask only for genuinely missing decisions or authorization.

When a proposal is authorized, map confirmed behavior to observable acceptance scenarios. Preserve the distinction between actual user decisions and simulated evaluation fixtures.
